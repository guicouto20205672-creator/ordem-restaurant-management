# ORDEM — Restaurant Management

Protótipo navegável de gestão de restaurante.

## Publicar com GitHub Pages
1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**.
4. Clique em **Save**. Aguarde o GitHub concluir a publicação.

Depois, o endereço será:
https://guicouto20205672-creator.github.io/ordem-restaurant-management/

## Módulos do protótipo
- Dashboard operacional
- Mapa de 16 mesas e comandas
- Lançamento de pedidos pelo atendimento
- Fila da cozinha (KDS): recebido → em preparo → pronto
- Cadastro e edição de produtos
- Resumo financeiro demonstrativo

## Limitações desta versão
Os dados ficam no armazenamento local do navegador. Não há autenticação real, banco de dados compartilhado, sincronização entre dispositivos, emissão fiscal, integração bancária ou ambiente de produção. Não use para operação comercial real. Essas capacidades exigem backend, banco, autenticação, regras de acesso e testes.
